
# SpendWise Budget Tracker

## Project Description

SpendWise is a personal budget and expense tracking web application designed to help users manage their money effectively.

The application allows users to set a monthly budget, record daily expenses, select expense categories, calculate total spending, and view their remaining balance.

It also provides a budget progress bar to help users monitor their spending and avoid exceeding their budget.

## Technologies Used

- HTML5 – Used to structure the website.
- CSS3 – Used to style the dashboard and make it responsive.
- JavaScript – Used to add interactive features and perform budget calculations.
- Google Fonts – Used for Roboto typography.
- Local Storage – Used to save budget and expense information.
- GitHub – Used for version control and source code hosting.
- Netlify – Used to deploy and publish the website.

## Project Features

- Set and update monthly budgets.
- Add new expenses.
- Select from different expense categories.
- Calculate total expenses automatically.
- Display remaining budget balance.
- Monitor budget usage with a progress bar.
- Delete individual expenses.
- Clear all expense records.
- Filter expenses by category.
- Save information using browser local storage.
- Responsive design for mobile and desktop devices.

## Technologies and JavaScript Concepts

### Variables
Variables store the total budget, total expenses, and remaining balance.

### Arrays
An array called `expenses` stores expense records.

### Functions
Functions are used to calculate expenses, update the dashboard, save information, and display transactions.

### Conditionals
If and else statements check budget limits, validate information, and display appropriate messages.

### Local Storage
Local storage saves the budget and expenses so that information remains available when the browser is reopened.
